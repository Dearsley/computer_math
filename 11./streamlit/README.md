# Веб-приложение для построения оптимальных маршрутов

Приложение выполнено на основе [заготовки GeoRoute_Base](https://github.com/Alexandre77777/GeoRoute_Base) для практической работы по маршрутизации. Оно ищет адреса через OpenStreetMap/Nominatim и показывает точки и маршрут на интерактивной Folium-карте с подложкой CartoDB Positron. В приложение добавлены загрузка дорожной сети, расчет кратчайших путей и выбор порядка объезда точек.

## Что есть в проекте

- `app.py` — интерфейс Streamlit, поиск адресов, работа с точками и карта.
- `graph_utils.py` — дорожный граф, веса ребер, кратчайшие пути и порядок объезда.
- `requirements.txt` — зависимости для запуска приложения.
- `README.md` — описание проекта и инструкция.

## Как запустить

Откройте терминал в папке `streamlit`.

### Linux и macOS

Создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите приложение:

```bash
streamlit run app.py
```

### Windows PowerShell

Создайте и активируйте виртуальное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установите зависимости и запустите приложение:

```powershell
pip install -r requirements.txt
streamlit run app.py
```

После запуска Streamlit покажет локальный адрес, обычно `http://localhost:8501`. Чтобы остановить приложение, нажмите `Ctrl+C` в терминале.

Для подложки CartoDB Positron нужен ключ [CARTO Basemaps](https://www.carto.com/basemaps/apikey/). Перед запуском задайте его в том же терминале:

```bash
export CARTO_BASEMAPS_API_KEY="ВАШ_КЛЮЧ"
```

В Windows PowerShell вместо этого выполните:

```powershell
$env:CARTO_BASEMAPS_API_KEY = "ВАШ_КЛЮЧ"
```

Без ключа CARTO покажет на подложке надпись `API KEY REQUIRED`. Не записывайте ключ в `app.py` и не добавляйте его в Git.

## Как работает фронтенд

1. Пользователь вводит адрес в поле поиска.
2. Приложение отправляет запрос в Nominatim, сервис геокодирования OpenStreetMap.
3. Если найдено несколько вариантов, они появляются в выпадающем списке.
4. Пользователь выбирает адрес и добавляет точку в список. Любую точку можно удалить.
5. Координаты и результаты поиска сохраняются в `st.session_state`.
6. После выбора критерия приложение загружает дорожный граф через OSMnx.
7. Для точек находятся ближайшие узлы графа и кратчайшие пути между ними.
8. Приложение выбирает порядок объезда, начиная и заканчивая маршрут в первой точке.
9. Folium-карта показывает маркеры и построенный маршрут. Под картой выводятся расстояние, время и порядок точек.

## Основные места в коде

- `get_geolocator()` в `app.py` создает клиент Nominatim.
- `search_address(query)` ищет адрес и возвращает найденные варианты.
- `build_route()` загружает дорожную сеть, рассчитывает маршрут и сохраняет результат.
- `create_map(points, route)` создает карту, маркеры и линию маршрута.
- `st.session_state.points` хранит выбранные точки, а `st.session_state.search_results` — последние результаты поиска.
- `graph_utils.py` содержит расчет весов ребер, кратчайших путей и порядка объезда.

## Задание

В приложении реализованы:

- добавление нескольких точек;
- удаление конкретной точки из списка;
- загрузка дорожного графа через OSMnx;
- расчет весов ребер по расстоянию, времени и коэффициентам комфорта;
- поиск кратчайших путей;
- построение матрицы расстояний между точками;
- выбор порядка объезда точек;
- отображение итогового маршрута на карте.

## Важное замечание про Nominatim

Nominatim — публичный сервис OpenStreetMap. Он не предназначен для массовых нагрузочных тестов. В коде есть небольшая задержка между запросами и кеш результатов поиска через Streamlit. По умолчанию поиск ограничен Россией:

```python
COUNTRY_CODES = "ru"
```

Для поиска по всему миру измените эту константу или уберите параметр `country_codes` в функции `search_address`.

Для поиска адресов, загрузки дорожной сети и подложки требуется доступ к интернету.
