# Практическая работа по веб-сервису преобразования координат

Файл Excel должен содержать столбцы Name, X, Y и Z. Сервер использует параметры перехода из практической работы по преобразованию координат.

Для локального запуска установите зависимости из `requirements.txt`. Запустите сервер командой `uvicorn main:app --reload`, затем интерфейс командой `streamlit run app.py`. В интерфейсе укажите адрес сервера, если он размещён отдельно.

Для размещения на Render используйте команду запуска `uvicorn main:app --host 0.0.0.0 --port $PORT`. Для Streamlit Cloud укажите файл `app.py`. После размещения впишите адрес сервера Render в поле «Адрес сервиса».
